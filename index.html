How to Host & Access This Site For Free Online

Step-by-step instructions for publishing this web app so Ron, David, and Nii can access it via a URL on mobile & PC.

GitHub Pages (Recommended)
  1. Create a free account at GitHub.com.
  2. Create a new public repository named nba-draft-tracker.
  3. Upload this file as index.html.
  4. Go to Settings > Pages and set Source to main branch.
  5. Your custom URL will be live at username.github.io/nba-draft-tracker.
Netlify Drop (Easiest / 30 Secs)
  1. Save this file on your computer as index.html.
  2. Go to app.netlify.com/drop.
  3. Drag & drop the folder containing your file into the browser box.
  4. Netlify instantly generates a custom live web URL you can share with your friends.
Vercel Hosting
  1. Sign up at Vercel.com using GitHub.
  2. Click Add New Project and select your GitHub repository containing index.html.
  3. Click Deploy.
  4. Vercel generates an SSL-secured custom link for instant access.
